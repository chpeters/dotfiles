# Cleanroom

Create a neutral minimal brief: the actual question, user requirements and settled constraints, raw evidence or artifact links, and unresolved facts. Exclude earlier verdicts, persuasive framing and proposed answers unless the question explicitly requires assessing them.

When delegation is available and authorized, give a fresh evaluator only that brief and the evidence needed to form a judgment. Ask it to inspect assumptions and strongest alternatives, with concrete reasoning and uncertainty. Do not provide the desired conclusion or coach the evaluation toward agreement.

Compare its reasoning with the existing position, resolving disagreements through evidence. Preserve user decisions and make tradeoffs explicit. If fresh context is unavailable, disclose that limitation; a second pass by the same context is not independent cleanroom evidence.

Return the independent judgment, material disagreements, evidence and implications. Do not implement or publish merely because the judgment favors a change.
